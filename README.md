En interaktiv matteapp byggd för att göra det enklare och roligare att öva på matte.

Projektet låter användare skapa ett konto, lösa mattefrågor och följa sin utveckling över tid. Eftersom användardata sparas i en databas kan man logga in från olika enheter, exempelvis både dator och iPad.
